## Project Overview

**AI 工作猎手 (AI Job Hunting)** — a Tampermonkey userscript + Spring Boot backend that automates job hunting on Boss 直聘 (zhipin.com). The AI "seat" acts as the user's proxy: auto-replies to HR messages, filters jobs, sends resumes, and handles payments.

The repo is a monorepo with two independently built subprojects. Bundled userscript artifacts live at the root for distribution.

## Commands

### Frontend (`ai-job-hunting-ui/`)

```bash
cd ai-job-hunting-ui
pnpm dev                     # Vite dev server (HMR, no bundle sync)
pnpm build                   # vue-tsc check → vite build → sync-dist.mjs copies bundle to root
pnpm test                    # vitest run (runs src/**/__tests__/**/*.spec.ts)
pnpm test -- --watch         # watch mode
```

Version is derived from `git rev-list --count HEAD` by default; set `USERSCRIPT_VERSION` env var to override. For release: `PUBLISH=1 pnpm build` writes `updateURL`/`downloadURL` into the userscript header.

### Backend (`ai-job-hunting-server/`)

```bash
cd ai-job-hunting-server
mvn spring-boot:run          # dev (requires application.properties edits for DB/AI keys)
mvn package                  # produce target/*.jar
mvn test                     # run unit tests
```

Default port: `9100`. Configuration in `src/main/resources/application.properties` (MySQL, Alipay, Kimi/OpenAI keys). Schema in `schema.sql`.

## Architecture Notes

### Userscript runtime model
The UI is packaged as a single userscript that injects into `zhipin.com/web/geek/*` and `zhipin.com/overseas/*`. It mounts a Vue app into a panel on the job-list page. The script also patches `window.WebSocket` (`webSocket/hookMain.ts`) to intercept Boss 直聘's internal chat protocol (protobuf over `.../chat`), decode it via `TechwolfChatProtocol`, and feed messages into the AI seat.

### State & server sync
Pinia stores (`stores/remote.ts`, `stores/server.ts`) read/write user state via `GM_setValue`/`GM_getValue`. `silentlyLogin` POSTs to `/api/user/silently/login` and caches results in Tampermonkey storage so the panel survives page navigations within Boss.

### Server AI dispatch
`AIServiceFacade` is the single entry point for all AI calls. It holds a `Map<String, AIService>` (autowired by Spring `@Service` annotation name) and routes by `AITypeEnum`. Providers: `KimiAIService` (Moonshot), `OpenAIService` (pool), `CustomOpenAIService` (user-configured endpoints), `DebugOpenAIPoolService`. Custom endpoints use `CompletionPathOpenAiApi` (extends Spring AI's `OpenAiApi` via reflection to swap the completions path and merge extra body params).

### Caching layer
All caches extend `frame/cache/AbsMemoryCache` (Guava `Cache` wrapper). Keys are typically `(userId, sessionId)` tuples. `MsgSessionStopCache` and `HighInterestInformCache` drive the AI-seat stop/resume and email-alarm logic.

### Payment flow
Alipay QR generation (`ALiPayController` → `ALiPayService`) returns a URL the userscript opens. Completion is confirmed via Alipay webhook (`/api/pay/paySuccessCallBack`) and SSE push to the client (`SseController`).

### Protocol constants
`consts/RePatternConstant.java` and `consts/AIPromptStrConstant.java` hold regexes for parsing Boss DOM/protocol and system prompts for the AI seat. Prefer extracting new patterns into these rather than scattering literals.

## Conventions

- **Java**: Lombok `@Builder @Data` on all `model/` and `entity/` classes. All controllers return `Response<T>`. Exception hierarchy: `ApplicationException` (business) → `AIPowerException` (AI-specific).
- **Vue/TS**: Auto-imports for Element Plus components (`unplugin-auto-import` + `unplugin-vue-components`). Tests mock Tampermonkey APIs via the `"$"` alias in `vitest.config.ts`; do not depend on `unsafeWindow` in testable code without using `TampermonkeyApi` wrapper.
- **Bundles**: `ai-job-hunting.bundle.user.js` at the repo root is the source-of-truth distribution artifact — always regenerate it via `pnpm build` in the UI subdir; never edit it by hand. The legacy `ai-job-hunting.user.js` (CDN-dependent) is kept only for GreasyFork listings.
- **Proto hook**: Do not modify `TechwolfChatProtocol` or the `hookMap` lifecycle in `hookMain.ts` without understanding the Boss WebSocket handshake — breaking it breaks the entire AI seat.
